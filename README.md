# Odin Recipes

Odin Recipes is my first project from The Odin Project curriculum. It is a simple recipe website built using HTML.

The website contains different recipes, including pizza, biryani, and chicken karahi. Each recipe page includes an image, a description, a list of ingredients, and step-by-step cooking instructions.

## Skills Demonstrated

- Creating HTML boilerplate
- Using headings, paragraphs, and lists
- Adding images to web pages
- Creating links between pages
- Organizing a website using multiple HTML files
- Publishing a website using GitHub Pages

## What I Learned

Through this project, I practiced the fundamentals of HTML, learned how to link multiple web pages together, and published my first website using GitHub Pages.
